YTDEVENTS DEMO WEBSITE
======================

FILES
- index.html: Home page
- about.html: About page
- services.html: Services page
- gallery.html: Gallery page
- packages.html: Packages page
- contact.html: Contact / enquiry page
- style.css: Shared design and responsive layout
- script.js: Mobile menu and demo form behavior

HOW TO USE ON YOUR PHONE (SPCK)
1. Create a new project/folder in SPCK named ytdevents-demo.
2. Extract this ZIP if your phone file manager supports it.
3. Copy all 8 files into the project root (same level; do not put HTML inside another folder).
4. Open index.html in Preview. Use the navigation links to test every page.
5. Upload all files together to the root of a GitHub repository for GitHub Pages.

IMPORTANT BEFORE SHOWING/PUBLISHING
- This is a demo concept based on the services provided in the WhatsApp reply.
- Replace +234 000 000 0000 and hello@ytdevents.com with verified details.
- Confirm package prices/inclusions with YTDEVENTS; package prices are placeholders.
- Gallery images are remote Unsplash stock photos and are illustrative, not verified client work. Internet is needed for them to load.
- The contact form is demo-only and does not send messages. Connect it to WhatsApp, email, or a form service before the final launch.
- The website uses Google Fonts and Unsplash images via internet URLs.
- Get the business owner's approval before using their name/logo or publishing as their official website.
